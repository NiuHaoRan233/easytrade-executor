# 通用交易测试台

双击 `Start-Test-Console.cmd`，或在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m easytrade.console --root .
```

窗口标题为“Easytrade 通用交易测试台”，构建号 `20261016.11`。启动不会主动发单，默认模拟模式。

首次切换实盘后，点击“客户端适配检查”，在“首次适配检查”页查看窗口大小、DPI、账户与委托读取情况，再人工对照。检查只读，详细步骤见[窗口适配](client-adaptation.md)。

## 选择证券与买卖

证券下拉列表来自当前模式配置中的 `instruments`，旁边显示名称、交易单位和价格最小单位。模拟读取 `paper.example.json`，实盘读取 `ths.local.json`；修改后重启。切换证券会清除旧报价。

填写数量、选择定价方式，分别点击买入或卖出。数量按配置的正整数倍校验，价格必须符合最小单位。没有自动往返交易，每次买卖都要独立指令。模拟立即成交，不模拟真实 T+1、停牌和撮合。

- **盘口限价**：买用卖一，卖用买一；默认读取客户端右侧行情。刷新查看最新价、涨幅和五档；缺少可靠字段显示“—”。过期、空盘口、休市或矛盾价格不能用于自动定价。
- **手填限价**：用户明确填写价格；不要求当前买一卖一有效，是否受理及成交由券商返回。
- **腾讯 Web**：通过行情来源主动选择；客户端读取失败不会暗中切换。

实盘每个新请求默认先读账户，再填写和核对委托。准备与提交期间不要切换前台、点击客户端或修改字段。

## 账户与委托

“刷新账户持仓”显示当前账户资金、持仓总数、可用数量及可取得的价格/市值，**不按证券下拉框过滤**。快照带时间与完整性标记；只有核对全部滚动范围才标记完整。读取不完整时，未读到不代表没有持仓。

市价、市值列被隐藏/截断、低置信、跨列或数值明显不一致时，相关数值显示“—”并给出原因；资金和可可靠识别的持仓数量仍可展示。关键代码/数量不可靠时，本次读取失败并标记旧快照。读取期间保持客户端窗口、列宽、缩放稳定。

“刷新委托状态”读取券商当日委托全表，包括手工委托；同时按完整编号和字段同步匹配的本地记录。本地执行记录与券商委托是两个独立视图。

选中本地记录后可查询回执；缺少编号时可补录完整委托号再核对。受理不等于成交，查询失败保留状态。旧待成交/UNKNOWN 不会禁止新明确指令，同编号不会再次提交。

## 停止、撤单和恢复

“停止后续步骤”停止后续准备或轮询，不能撤回已送达券商的委托。撤单会核对所选记录的账户、完整编号与剩余状态后执行，是实际交易操作。

恢复确认、声明从未提交等按钮用于人工核对遗留记录，仅在明确记录与现场对应后使用。不能根据查询空表推断没有提交；测试台不自动选择恢复操作。

## 常见现象

| 现象 | 处理 |
| --- | --- |
| 买一或卖一为零 | 可能收盘或盘口不可用；刷新查看，或明确使用手填限价 |
| 已成交，本地仍待成交 | 刷新券商委托并查询完整编号，不能靠改本地状态确认成交 |
| 身份核对期间前台变化 | 等待读取完成，不操作其他窗口，再查询；失败不会补单 |
| 新证券不出现 | 修改当前模式配置，重启并核对客户端名称 |
| 可用数量小于总持仓 | 以券商可用数量为准，可能受 T+1、冻结等规则影响 |
| 仍显示旧标题 | 关闭旧测试台，重新运行根目录脚本并检查构建号 |
